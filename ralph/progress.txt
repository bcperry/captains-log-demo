# Ralph Progress Log
Started: 2024-01-15

## Codebase Patterns
- Package manager: Prefer `uv` over pip (e.g., `uv add`, `uv run`, `uv sync`)
- Migrations: Use alembic with `op.create_table` idempotent checks
- FastAPI: Use `Depends()` for dependency injection
- FastAPI Auth: Use `get_current_user` dependency for protected endpoints, `request.state.user` for access
- Pydantic: Inherit from BaseModel, use Field() for validation
- Async: Use `async def` with `await` for I/O operations
- Testing: Use pytest fixtures, mock external services with `unittest.mock`
- Testing FastAPI: Use `TestClient` from `fastapi.testclient` for HTTP testing
- Type hints: Always annotate function signatures
- Docker: Use multi-stage builds, copy uv from ghcr.io/astral-sh/uv:latest
- Bicep: Use `@allowed` for param validation, conditional modules with `if (condition)`
- Bicep Entra: Use `authsettingsV2` for App Service auth (app registrations require MS Graph API)

## Key Files
- `app/pyproject.toml` - Project dependencies and configuration
- `app/uv.lock` - Locked dependency versions for reproducible builds
- `app/app.py` - Main Streamlit application (AudioTranscriber, AzureOpenAISummarizer)
- `app/config/settings.py` - Centralized configuration with Pydantic Settings
- `app/auth/entra.py` - Azure Entra ID JWT token validation
- `app/auth/dependencies.py` - FastAPI auth dependencies (get_current_user, get_optional_user)
- `app/api/auth.py` - User profile endpoints (GET /auth/me, PATCH /auth/me/preferences)
- `app/api/transcribe.py` - Audio transcription endpoint (POST /transcribe)
- `app/models/user.py` - User profile Pydantic models
- `app/models/transcription.py` - Transcription request/response models
- `app/db/cosmos.py` - Cosmos DB client with in-memory fallback
- `app/speech/client.py` - Azure Speech Services client with Government cloud support
- `Dockerfile` - Container build using uv for package management
- `infra/entra-auth.bicep` - App Service Entra ID authentication settings
- `docs/entra-id-setup.md` - Azure Entra ID app registration setup guide
